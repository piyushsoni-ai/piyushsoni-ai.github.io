SEO Master Skill

An AI-assisted SEO workflow designed for technical audits, GEO/AEO, competitor research, structured data, content analysis, and reporting.

View on GitHub (opens in a new tab)Read the case study

Problem

SEO workflows often require information from multiple tools, repeated checks, and manual analysis. Generic AI prompts make this worse: they skip steps, guess at data they do not have, and produce reports nobody can act on.

Solution

SEO Master Skill organizes technical SEO, GEO/AEO, competitor analysis, structured data, content research, and reporting into reusable AI-assisted workflows. It is a set of instruction files rather than one long prompt, so an agent knows what to check, which tools to use, what to do when a tool is missing, and how to report without inventing numbers.

My role

Author and maintainer. I wrote the workflow logic, audit modes, data rules and report templates from my own agency audit process.

How it works

The agent reads SKILL.md first, then pulls in supporting modules for onboarding, capability detection and audit modes. Before starting, it checks which data sources are available and picks one of five modes: full intelligence, Apify intelligence, native agent scraping, file analysis, or advisory only.

From version 1.0.2 the skill is Apify-first. By default it asks for one token, APIFY_API_TOKEN, and uses Apify actors for crawling, SERP data, competitors, Maps and reviews, Trends and PageSpeed. Other APIs are only requested later if Apify cannot get the data.

Version 1.0.3 added AI-friendly SEO modules: an AEO writing persona, GEO citation optimization, an entity knowledge graph system, a reputation proof stack and a conversation SEO framework.

Rules it follows

If data is missing, the skill says so. It does not invent rankings or search volume, does not recommend keyword stuffing or backlink spam, and does not promise results. Those rules matter more to me than any single feature, because client reports built on guessed numbers do real damage.

Where it runs

Codex, Claude Projects, OpenClaw, Cursor, MCP-enabled agents and custom file-based agents. The repository is public under the MIT license.
