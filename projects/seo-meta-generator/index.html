Hugging Face Space

AI SEO Meta Tag Generator

LLM-assisted tool for drafting SEO titles, meta descriptions, and Open Graph metadata.

Open the tool (opens in a new tab)

Problem

Writing titles and descriptions for hundreds of pages is repetitive, and first drafts tend to run too long, repeat the keyword or forget the brand.

Solution

Enter a keyword, a brand name and an optional benefit or year. The tool returns several title tag options, meta descriptions and complete Open Graph HTML ready to paste. A person still picks and edits the final version.

My role

Designed and built the tool.

Inputs and outputs

  • Inputs: target keyword, brand name, optional benefit or year
  • Outputs: title tag options, meta descriptions, Open Graph HTML
