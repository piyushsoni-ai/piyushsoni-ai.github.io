SEO AI Citation Audit

A quick technical SEO and AI citation readiness check: enter a URL and it reviews the HTML, robots.txt, sitemap and llms.txt.

Open the tool (opens in a new tab)

Problem

Before a page can be cited in an AI answer, the basics have to be right: the page must be crawlable, the AI crawlers must not be blocked, and the content must be clearly marked up. Checking this by hand for every prospect or client page is slow.

Solution

A small web tool that fetches a site's HTML, robots.txt, sitemap and llms.txt without needing an API key, then runs checks on HTTPS, title, meta description, headings and schema. It gives a fast first read on whether a page is ready for AI Search visibility work.

My role

Designed and built the tool and its checks.

What it checks

  • HTTPS
  • Title tag and meta description
  • Heading structure
  • Structured data
  • robots.txt, XML sitemap and llms.txt presence

Good to know

Free Hugging Face Spaces go to sleep when idle. If the page says the Space is sleeping, restart it and give it a few seconds.
