Case study

Building SEO Master Skill for AI-assisted search workflows

Most SEO prompts produce confident reports built on guessed numbers. I wanted an agent that audits the way an experienced SEO does, and says so when it does not have the data.

The starting point

I had a working audit process: what to check, in what order, which exports to ask for, how to prioritize findings and how to present them to a client. Running it with general AI assistants kept failing the same ways. They skipped steps, asked for every API up front, or filled gaps with made-up search volumes.

A file-based system, not a prompt

SEO Master is structured like a small operating manual. SKILL.md holds the role, rules and core workflow. Separate modules cover onboarding, capability detection, audit modes, playbook depth and report templates. An agent reads the master file first and loads the rest only when the task needs it, which keeps context small and behavior consistent.

Capability detection and audit modes

Before any audit, the agent checks what it can actually use: APIs, connected tools, uploaded exports, plain web access. It then picks one of five modes, from full intelligence down to advisory only. The output is honest about which mode it ran in, so a client knows how much of the report rests on measured data.

Going Apify-first

Early versions asked for too many credentials. In version 1.0.2 I changed the default to a single Apify token, with Apify actors covering crawling, SERP data, competitors, Maps and reviews, Trends and PageSpeed. Other APIs became optional fallbacks. Fewer setup questions meant people actually ran the full workflow.

Adding AI-friendly SEO

Version 1.0.3 added modules for AEO writing, GEO citation optimization, entity knowledge graphs, reputation proof and conversation SEO, so one request can produce a combined SEO, AEO, GEO and entity report.

Lessons

  • Rules about data honesty matter more than any individual check.
  • Portability across Codex, Claude Projects, OpenClaw, Cursor and MCP agents comes from plain files and clear structure, not from platform tricks.
  • A good default beats a long setup checklist.
